# Nishant Trivedi — Portfolio

An interactive, scroll-driven story portfolio: doubts become "adaptations", the wheel turns, and every project is a level.

- Live: https://nishant-trivedi.netlify.app
- Recruiter view (plain, 30 seconds): https://nishant-trivedi.netlify.app/#recruiter
- Run locally: open `index.html` in a browser (best with sound on).

## What's inside

- **The story**: a gate, five doubts, the adaptation wheel, a five-card deck and the Level 99 reveal.
- **Each project is a level**: every project opens into an adaptation log (the threat, how I adapted, the result). LV 01 includes a live pipeline diagram.
- **Levels cleared**: education and work history as a timeline.
- **Skill wheel**: eight spokes, each linked to the projects that prove it.
- **Recruiter view**: a plain one-screen summary, opened from the gate, the nav, the footer, the terminal or `#recruiter`.
- **Hidden terminal**: press <kbd>`</kbd> or click `>_`. Try `help`, `found` or `sudo hire nishant`.
- **Hidden adaptations**: 8 achievements to discover.
- **Contact form**: Netlify Forms with a honeypot field.
- `404.html`: a themed not-found page. `og.png`: the link-preview image.
